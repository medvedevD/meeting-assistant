# Structured Protocol Rendering

## Context

During the Qt redesign, `MeetingDetailScreen` received an improved
Markdown-based Editorial renderer. It now handles common protocol Markdown well
enough for the current redesign phase, but the Meety mockups assume a structured
protocol model rather than arbitrary Markdown.

## Goal

After the current redesign work is complete, replace the QML heuristic Markdown
shaping with a stable protocol rendering contract.

## Options To Evaluate

- Strict Markdown template generated by the LLM and rendered by known sections.
- Structured protocol output, for example `title`, `summary`, `topics`,
  `decisions`, `actions`, `open_questions`.

## Expected Outcome

`MeetingDetailScreen` can render the protocol nearly one-to-one with the Meety
mockups without relying on fragile Markdown heuristics.
